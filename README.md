# ❤️ A Special Surprise Website For Mummy

Ek khubsoorat, handmade digital scrapbook aur emotional love letter, specially banaya gaya meri pyari Mummy ke liye.

---

## 🌸 Features & Pages

1. **Page 1: Welcome Surprise** — "Hey Mummy! ❤️", "Aapke liye maine kuch special banaya hai...", "Do you want a little surprise?", Mummy ki pyari Polaroid photo, aur "YES!! ❤️" / "NO!! 🥺" buttons.
2. **Page 2: Funny NO Page** — "NOOOOO!!! Phir se socho! 🥺💔", crying bear mascot animation with tears, aur "Achha chalo, wapas chalte hain ❤️".
3. **Page 3: Hamari Kuch Pyari Yaadein 💗** — Scrapbook-style photo gallery with Polaroid frames, washi tape, stamps, stickers, Hinglish captions, and click-to-zoom Lightbox modal.
4. **Page 4: Ek Chhota Sa Letter Aapke Naam Mummy 💌** — Wax-sealed interactive envelope that unfolds with confetti into a handwritten letter on stationery with your exact emotional Hinglish letter.
5. **Page 5: Aap Mere Liye Itni Special Kyun Ho? ❤️** — 6 interactive animated cards highlighting unconditional love, endless support, smile, strength, care, and happiness.
6. **Page 6: Final Photo Gallery & Surprise** — Memory collage with all personal photographs, final emotional tribute ("Mummy, agar mujhe har lifetime mein..."), confetti cannon, and a secret surprise button ("Secret Surprise! 🤫💌").
7. **🎵 Mummy's Melody Player** — Soothing music-box lullaby synthesizer using the Web Audio API with Play/Pause and Mute/Unmute controls (no external mp3 files needed, 100% offline-ready).

## 🚀 How to Run Locally

### Option 1: Double-Click (Direct Browser)
Simply double-click `index.html` or right-click `index.html` → **Open with** → **Google Chrome / Microsoft Edge / Safari / Firefox**.

### Option 2: VS Code Live Server
1. Open the `Desktop/mummy ji/` folder in VS Code.
2. Right-click `index.html` and click **"Open with Live Server"**.
3. It will open at `http://127.0.0.1:5500/index.html`.

---

## 🌐 How to Deploy Online (Free & Fast)

### Netlify Drop (10 Seconds, No Terminal Needed)
1. Visit [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop the `mummy ji` folder into the browser.
3. You will immediately get a live HTTPS link to send to Mummy!

### GitHub Pages
1. Push this folder to a GitHub repository.
2. Go to **Settings** → **Pages** → Source: **Deploy from a branch (main / root)**.
3. Your site will be live!
